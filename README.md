# Our Memory Archive 🌸

A soft, personal digital scrapbook preserving the story of a relationship — its moments, music, and memories — from **December 20, 2023** to **April 14, 2026**.

> *846 days. Every single one, kept.*

---

## What This Is

This is a static website built as a memory archive — not a countdown, not a live tracker, but a quiet place to hold something that mattered. It includes a written story, a photo gallery, a personal music playlist, a personal dedication page, and a relationship timeline that has been intentionally paused. All pages now share one unified visual design system (ivory/rose color palette, Cormorant Garamond + Inter typefaces) instead of separate one-off styles.

---

## Pages

| File | What's Inside |
|------|--------------|
| `index.html` | Homepage — hero, a featured "Now Playing" song, the full About Us story, a mini timeline (Grade 4 → Dec 20, 2023 → Apr 14, 2026), an Important Dates list, and a Navigate grid to the other pages |
| `gallery.html` | Photo gallery (13 photos) with a fullscreen modal viewer — click/tap to open, arrow buttons or ←/→ keys to move between photos, Esc or backdrop click to close, and a caption for each photo |
| `playlist.html` | Personal music playlist — 6 songs, each with its own album art, custom play/pause + seek-bar audio player, and a toggleable description explaining what the song means |
| `howlong.html` | Paused relationship timeline |
| `allaboutyou.html` | A personal dedication page, restyled to match the site's shared design system |
| `polish.css` | Shared design system (colors, typography, layout) and UI styles used across all pages |
| `polish.js` | Page transitions and navigation, now with `prefers-reduced-motion` support so transitions are skipped for users who prefer reduced motion |

> Note: an earlier "Messages for You" page (`messages.html`) has been removed from the site.

---

## Features

- Unified, clean ivory/rose design system shared across every page (previously each page had its own styling)
- Rounded modern UI with smooth page transitions, now motion-sensitivity aware
- Mobile-friendly bottom navigation
- Apple-inspired music player design, on the homepage and throughout the playlist
- Fullscreen photo modal with keyboard and click navigation between photos
- Per-song audio controls (play/pause, seek bar, expandable description) on the playlist page
- Relationship timer **intentionally paused** at 846 days
